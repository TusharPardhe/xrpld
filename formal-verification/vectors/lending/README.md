# Lending vectors

Rust-backed fixture constructors are grouped under `rust/crates/parity-harness/src/lending/vectors/`; operation runners remain in the parent Lending directory. Public raw, terminal, atomicity, accept, and delete regressions live under `rust/tests/lending/`.

Stable IDs and classifications are defined in `../schemas/catalog.toml`. All 27 raw/terminal wire routes plus seven scalar exports are executed; bounded vectors are not a universal refinement proof.
